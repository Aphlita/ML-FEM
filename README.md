# A1-13 ML-KEM Platform

本仓库用于全国密码技术竞赛复赛 A1-13 方向的实验平台开发。当前目标是把 ML-KEM 基本功能、公开测试向量验证、固定 CPU 核时间采集、统计分析、定位说明、常数时间防护与复测流程逐步整合到一个可演示的平台中。

## 当前已完成

- Web 平台基础框架
- ML-KEM-512、ML-KEM-768、ML-KEM-1024 基本功能接入
- 密钥生成、封装、解封装接口
- 共享值一致性验证
- 公开测试向量验证接口
- 固定 CPU 核短实验计时检测接口
- 前端结果展示页面

## 目录结构

```text
backend/     平台后端接口
frontend/    浏览器页面
core/        第三方 ML-KEM 实现，作为子模块记录
scripts/     构建和启动脚本
tests/       基础测试
docs/        项目文档
data/        后续数据目录
deploy/      后续部署目录
```

## 子模块

核心实现来自：

```text
https://github.com/pq-code-package/mlkem-native.git
```

首次克隆后请执行：

```bash
git submodule update --init --recursive
```

## 构建

```bash
./scripts/build.sh
```

## 启动

```bash
./scripts/start.sh
```

平台默认只监听本机地址：

```text
127.0.0.1:8000
```

如果在远程服务器运行，可以使用 SSH 端口转发访问：

```bash
ssh -p <PORT> -L 8000:127.0.0.1:8000 <USER>@<HOST>
```

然后在本地浏览器打开：

```text
http://127.0.0.1:8000
```

## 后续开发重点

1. 自动样本生成模块。
2. 统计分析增强，包括均值、方差、分位数、置信区间和显著性检验。
3. 定位模块，把时间差异对应到函数或代码位置。
4. 常数时间防护改造与复测。
5. 实验报告与日志一键导出。
