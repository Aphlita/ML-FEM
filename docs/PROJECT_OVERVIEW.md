# 项目总览

## 1 我们现在在做什么

我们参加的是 A1-13 题目：ML-KEM 解封装实现的时间侧信道检测与常数时间防护。

通俗理解，这个项目要做成一个实验平台。平台需要完成一条完整实验链路：

```text
ML-KEM 基本功能验证
-> 自动生成不同类别测试样本
-> 固定环境重复采集运行时间
-> 用统计方法判断不同类别是否存在可区分时间差异
-> 定位差异可能来自哪里
-> 修改实现方式进行防护
-> 重新测试并比较前后效果
-> 导出报告和复现实验材料
```

当前我们先做的是平台雏形和基础实验能力，还没有完成最终作品的全部模块。

## 2 目前已经完成什么

已完成：

- Web 平台基础框架。
- 后端 API 服务。
- 前端页面。
- ML-KEM-512、ML-KEM-768、ML-KEM-1024 基本功能接入。
- 生成、封装、解封装接口。
- 共享值一致性验证。
- 公开测试向量验证接口。
- 固定 CPU 核短实验计时检测接口。
- 时间检测结果前端展示。
- 基础测试脚本。

当前平台能说明：

- 我们已经能把 ML-KEM 功能接入平台。
- 我们已经能固定 CPU 核做时间采集。
- 我们已经能解析实验日志并展示时间差异。

但当前还不能说明：

- 已经完成最终标准的解封装输入分类实验。
- 已经完成完整统计检测。
- 已经完成定位模块。
- 已经完成常数时间防护和改造前后复测。

## 4 队员应该先看什么

建议阅读顺序：

1. `README.md`：知道怎么构建和运行。
2. `docs/PROJECT_OVERVIEW.md`：知道项目整体目标和当前进度。
3. `docs/ONBOARDING.md`：知道如何拉代码、初始化子模块、启动平台。
4. `docs/MODULES_AND_TASKS.md`：知道接下来每个模块要做什么。
5. `backend/server.py` 和 `backend/mlkem_service.py`：理解后端接口。
6. `frontend/index.html` 和 `frontend/app.js`：理解前端页面。

## 5 当前最重要的开发方向

优先级从高到低：

1. 自动样本生成模块。
2. 标准解封装计时实验模块。
3. 统计分析增强模块。
4. 报告导出模块。
5. 定位模块。
6. 常数时间防护改造和复测模块。
7. 跨环境对比和持续回归测试。

## 6 我们现在的定位

现在这个仓库可以看作：

```text
A1-13 作品的初始平台版本
```

不是最终完成版。队员接手后，应该围绕 `docs/MODULES_AND_TASKS.md` 中的任务继续补模块。
